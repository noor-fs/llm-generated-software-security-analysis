ABOUT THE PROJECT

A banking demo built
to ask better questions.

DemoBank is a fictional application created for the academic project Security Analysis of LLM-Generated Software.

⌑

Study security by design

Explore practical controls such as password hashing, CSRF tokens, safe SQL access, and access-controlled routes.

⇄

Real app behaviour

Users, demo accounts, balances, transfers, transaction history, and notifications are persisted in SQLite.

⌁

Safe by scope

All funds are fictional. No payment rails, real banking integrations, or external services are used.

Academic use only

This is not a real bank and is not intended for production financial services. Demo credentials are public by design. Never enter real financial information.
