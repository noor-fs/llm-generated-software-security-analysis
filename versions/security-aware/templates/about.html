About DemoBank

Banking as a learning experience.

DemoBank is a fictional banking web application created for the university project Security Analysis of LLM-Generated Software.

What is this application?

It simulates common online banking journeys using virtual accounts and fictional funds. Users can register, view balances, transfer demo funds, and review transaction activity.

Why was it built?

The project provides a realistic application surface for examining common web security weaknesses, testing security tools, and comparing an initial AI-generated implementation with a security-enhanced version.

Important: DemoBank is not a real financial institution. It does not connect to banks, payment networks, or real accounts. All balances and transfers are fictional.
