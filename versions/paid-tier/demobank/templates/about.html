THE STORY BEHIND DEMOBANK

A banking experience built for exploration.

DemoBank is a fictional web application created as part of the university project Security Analysis of LLM-Generated Software.

◈

Academic by design

Designed for evaluating software functionality, application security and AI-generated code.

◎

Completely virtual

Balances and transactions exist only in a local SQLite database. No real payments or accounts.

▣

Local and testable

Run the application on your computer, inspect the source and create dedicated demo data.

Important notice

DemoBank is not a real bank, is not affiliated with any financial institution, and should never be used to handle real money, personal financial credentials or sensitive production data. This educational application is not independently security audited.
